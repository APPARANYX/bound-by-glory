This is a thin adapter. The procedure lives in the repository, not here:

2. For the full spec-driven path, follow `docs/agents/spec-kit.md`. To run a Spec Kit command, read `.muse/commands/speckit.<command>.md` and follow it with the user's request as `$ARGUMENTS`.
3. Follow `AGENTS.md` and `docs/agents/working-rules.md` throughout (merges need the owner's word; Muse/Kit owns browser tests and benchmark launches).
